Privacy Policy

Applies to the "AI Explainer Channel" uploader app. Last updated 17 November 2026.

What this app is

A personal tool run by the owner of the "Explained in 60 Seconds" YouTube channel. It generates short educational videos and uploads them to that one channel using the YouTube Data API.

Data it accesses

The app requests a single Google permission: youtube.upload, used only to upload videos to the owner's own channel. It does not read, collect, store or share any other Google user data, and it is not offered to other users.

Storage

The login token is stored only on the owner's own computer. No data is sent to any server other than Google's YouTube API and the text-to-speech service used to create voiceovers (which receives only the video script).

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.

Google policies

This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
