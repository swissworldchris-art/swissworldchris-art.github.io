Privacy Policy

Applies to the "AI Explainer Channel" publishing app. Last updated 19 November 2026.

What this app is

A private tool run by one person on their own computer. It publishes that person's own videos to their own YouTube channels – Tales and Streams, Explained in 60 Seconds and Bible Storytime for Kids – using YouTube API Services. It is not offered to other users and has no public sign-up.

YouTube API Services

This app uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

The app signs in with Google OAuth to the owner's own account only, and requests these permissions:

  • youtube.upload – upload the owner's videos to the owner's channel.
  • youtube.readonly – read the signed-in channel's name and ID (to confirm it is the right channel before uploading), the owner's own videos, playlists and live broadcasts.
  • youtube – create the owner's playlists, add the owner's uploads to them, and set thumbnails and descriptions on the owner's own videos and live streams.

It does not access, collect or store any other person's data, comments, subscribers or analytics.

How the data is used and stored

  • The sign-in token and a log of the owner's own uploads (video IDs, titles, publish times) are stored only on the owner's own computer.
  • Recordings of the owner's own finished live streams are downloaded to that computer to cut Shorts, and are deleted once the clips are made.
  • No data is sold, shared with third parties, or sent to any server other than Google's YouTube API. Explainer voiceovers are created with a text-to-speech service that receives only the video script.

Retention and deletion

Downloaded stream recordings are deleted after clipping. The upload log contains only the owner's own video information (IDs, titles, publish times) and is kept so the same clip or title is never posted twice. To delete everything, the owner removes the token and log files from their computer and revokes access (below).

Revoking access

Access can be revoked at any time on the Google security settings page (also reachable at myaccount.google.com/permissions).
